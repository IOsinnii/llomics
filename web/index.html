llomics in the browser

Turn a 20,000-row results table into a small payload an LLM can reason over, and decide in code what its answers are allowed to settle.

Starting Python… Source on GitHub
  1. Pipeline resulta differential table or marker table, often thousands of rows
  2. Wrapcode builds one small state per contrast or cluster, with its quality checks
  3. Askthe model answers fixed questions about one unit at a time
  4. Gatecode sends each unit to auto or review, with a reason code

Everything on this page runs in your browser with Pyodide, the same Python code as the package. Files you load are not uploaded anywhere, and this demo makes no model calls.

Eleven simulated limma analyses, each with a known correct decision. Nine have a planted problem (a confounded batch, too few replicates, a sex imbalance, sample-handling stress…) and two are clean. Before any model is asked, the trust checks and facts computed by llomics decide which ones must go to a person.
